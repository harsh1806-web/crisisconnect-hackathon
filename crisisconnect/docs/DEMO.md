# CrisisConnect Demo Flow

## Demo Objective

Demonstrate how CrisisConnect connects a person in need with a nearby
volunteer and enables real-time emergency coordination.

---

# Demo Scenario

A citizen needs emergency assistance.

For example:

> A person needs urgent medical assistance and creates a high-priority
> emergency request.

---

# Demo Steps

## 1. Open Application

- Open the CrisisConnect application.
- Show the landing/login screen.

## 2. Login as Citizen

- Select Citizen.
- Login to the application.
- Show the Citizen dashboard.

## 3. Create Emergency Request

- Select "Create Request".
- Select emergency type.
- Select priority.
- Enter emergency description.
- Add location.
- Submit the request.

Expected result:

The emergency request should be successfully created.

## 4. Show Emergency Request

- Open the Requests section.
- Show the newly created emergency request.
- Highlight:
  - Emergency type
  - Priority
  - Location
  - Status

## 5. Login as Volunteer

- Switch to the Volunteer account.
- Open the Volunteer dashboard.
- Show nearby emergency requests.

## 6. Accept Emergency Request

- Open the emergency request.
- Click "Accept Request".

Expected result:

The request should be assigned to the volunteer.

## 7. Show Real-Time Status

Demonstrate the status progression:

Request Created
        ↓
Volunteer Assigned
        ↓
Volunteer On The Way
        ↓
Help Delivered
        ↓
Completed

## 8. Show Map

- Open the map.
- Show emergency location.
- Show volunteer/request location if available.

## 9. Complete Request

- Mark the request as completed.
- Show the updated status.

---

# Features To Highlight

During the demo, highlight these features:

- Real-time emergency requests
- Volunteer coordination
- Location-based assistance
- Emergency priority
- Request status tracking
- Map integration
- Verified users/organizations
- Simple and responsive UI

---

# Final Demo Message

CrisisConnect helps connect people who need emergency assistance
with nearby volunteers and organizations through a centralized,
real-time emergency coordination platform.

The goal is to reduce response time and make emergency assistance
more organized, transparent, and accessible.
